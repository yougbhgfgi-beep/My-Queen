# 💖 موقع "بوابة حبنا" — دليل الاستخدام

موقع حب رومانسي مبني بـ **Vite + React + Tailwind CSS**.

---

## 🚀 التشغيل

```bash
npm install        # أول مرة فقط (تحميل المكتبات)
npm run dev        # تشغيل الموقع للتجربة (افتح الرابط اللي يظهر)
npm run build      # بناء نسخة نهائية (تطلع في مجلد dist)
```

---

## ✏️ أهم حاجة: ملف الإعدادات ✅

**كل تعديل في الموقع من ملف واحد:**

```
src/config/siteConfig.js
```

منه بتعدل:

| الحاجة | مكانها في الملف |
|---|---|
| كلمة السر | `password` |
| الأسماء والعناوين | `names` |
| التواريخ (عدادات الوقت) | `dates` |
| رسالة من القلب | `loveMessage` |
| خط الذكريات | `timeline` |
| ليه بحبك | `reasons` |
| المشهد الأخير | `finalScene` |

---

## 🖼️ إضافة الصور الجديدة

1. حط ملفات الصور في مجلد: **`public/images/`**
2. افتح `src/config/siteConfig.js` وعدّل المسارات في قسم `images`:

```js
images: {
  timeline1: "/images/timeline-1.jpg",   // صورة الذكرى الأولى
  timeline2: "/images/timeline-2.jpg",   // صورة الذكرى التانية
  gallery: [                              // صور المعرض
    "/images/gallery-1.jpg",
    "/images/gallery-2.jpg",
    // ... زود أو قلّل زي ما تحب
  ],
},
```

> 💡 لو الصورة لسه متحطتش، الموقع بيظهر مكانها "ضع صورتك هنا 💕" مع اسم الملف المطلوب.

---

## 🎵 إضافة الأغنية والفيديو

1. حط الملفات في مجلد: **`public/media/`**
2. عدّل المسارات في قسم `media`:

```js
media: {
  audio: "/media/song.mp4",   // الأغنية
  video: "/media/video.mp4",  // الفيديو
},
```

> لو عايز تغيّر اسم الملف، غيّر الاسم هنا وفي المجلد بنفس الشكل.
